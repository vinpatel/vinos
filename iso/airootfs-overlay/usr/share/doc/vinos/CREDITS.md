# vinOS — Credits

You're running vinOS. Every polished piece of this desktop, every kernel line, every keybind that just works — traces back to people who made it possible.

## The stack you're using right now

**Kernel** — Linux (Torvalds et al.), the linux-hardened patch set (Arch community + KSPP), linux-cachyos scheduling patches (CachyOS), linux-t2 patches (t2linux). GPL-2.0.

**Base OS** — [Arch Linux](https://archlinux.org). Every package on this system carries its own upstream copyright — see `/usr/share/licenses/`.

**Desktop foundation** — [Omarchy](https://omarchy.org) by David Heinemeier Hansson (Basecamp). MIT. Hyprland compositor, Waybar bar, Walker launcher, Mako notifications, Hyprlock lock screen, and the 19 themes you can browse via `omarchy menu`. vinOS is an upstream-tracked fork of Omarchy.

**Cursor** — Bibata Modern Ice. GPL-3.0.
**Prompt** — Starship. ISC.
**Sounds** — sound-theme-freedesktop. LGPL-2.1.

**Agent CLI + Waybar AI pill + hardened defaults + T2 Mac support + LUKS installer** — © 2026 Vin Patel. MIT. See `/usr/share/licenses/vinos/`.

**Companion products by the same maintainer:**
- [AgenticFlow](https://agenticflow.do) — agent orchestration
- [vinos.computer](https://vinos.computer) — the vinOS project site

**Cloud model provider (default agent brain):** [Anthropic Claude](https://claude.ai) via the Anthropic API.
