### Rollback contracts
- **ISO:** any shipped release re-flashable from `dl.vinos.computer/releases/vX.Y.Z/`. Retention: forever for tagged.
- **Config:** BTRFS + Snapper snapshots per-boot. `snapper rollback` = one command.
- **Kernel:** multi-kernel Limine, reboot to alternative.
- **Omarchy:** LKG-tagged (`omarchy-lkg-<date>`). `git subtree pull` to LKG.
- **Arch:** snapshot-pinned per ISO, retained on R2 for 12 months.

### Disaster recovery drill (quarterly)
1. Wipe spare laptop
2. Flash latest ISO from `dl.vinos.computer`
3. LUKS install
4. Canary routine
5. Time-to-agent < 5 min (QA-4)
6. Log in `docs/v2/disaster-recovery-log.md`

Fail = halt forward development until it passes.
