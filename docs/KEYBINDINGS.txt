vinOS keybindings — cheat sheet
================================

NOTE: this static file is a fallback. Super+K launches
`vinos-cheatsheet` which parses ~/.config/hypr/hyprland.conf
live, so the source of truth is always the config, not this file.

APP LAUNCHERS
  Super + Return        Terminal (foot)
  Super + Space         App launcher (walker)
  Super + D             App launcher (walker)
  Super + E             File manager (nautilus)
  Super + F             File manager (nautilus)
  Super + B             Web browser (chromium)
  Super + N             Neovim in terminal
  Super + T             btop system monitor
  Super + M             Music (spotify)
  Super + G             Messenger (signal-desktop)
  Super + H             Notes (obsidian)
  Super + /             Password manager (1password)

MENUS
  Super + Ctrl + O      vinOS menu (bundles, wifi, theme, doctor, lock)
  Super + K             Show these bindings (live cheatsheet)
  Super + Shift + /     Same — Super + ?

AI
  Super + A             Local AI chat (ollama via vinos-ai)
  Super + Shift + A     Claude Code CLI

CONTROL PANELS
  Super + Ctrl + W      Wi-Fi (impala TUI over iwd)
  Super + Ctrl + B      Bluetooth
  Super + Ctrl + U      Audio mixer
  Super + Ctrl + S      System diagnostics (vinos-doctor)
  Super + Ctrl + T      Switch theme

CAPTURES
  Super + P             Region screenshot + annotate (satty)
  Super + Shift + P     Region screenshot → clipboard
  Print                 Region screenshot → clipboard
  Super + Shift + C     Color picker (hyprpicker)

NOTIFICATIONS
  Super + ,             Dismiss latest notification
  Super + Shift + ,     Dismiss all

WINDOW MANAGEMENT
  Super + Q             Close focused window
  Super + Shift + F     Fullscreen
  Super + V             Toggle floating
  Super + L             Lock (hyprlock)
  Super + Shift + E     Exit Hyprland
  Super + drag (LMB)    Move window
  Super + drag (RMB)    Resize window

WORKSPACES
  Super + 1..9          Switch to workspace N
  Super + Shift + 1..9  Move focused window to workspace N

MEDIA (function-row / XF86 keys)
  Volume up/down/mute      swayosd OSD popup
  Brightness up/down       swayosd OSD popup
  Play/pause/next/prev     playerctl
