what you get

An entire Wayland desktop, pre-configured with taste.

No dotfile hunt. No config rabbit hole. Boot into Arch, run one command, and you're at a working Hyprland desktop with keybindings, themes, and AI tools that already make sense.

Hyprland, tuned

Wayland-native compositor with the beauty pass applied — animations, blur, gradient borders, Nerd Font waybar, Bibata cursor. It just looks right.

AI-native

Super+A opens vinos-ai chat (ollama). Super+Shift+A opens Claude Code. Install with vinos-install-ai, no fiddling.

Bundles, not bloat

Base is lean. Add what you use — ai · dev · media · office · gaming · productivity · comms · browser — each is one command, always idempotent.

Themes that swap live

Five palettes ship: tokyo-night · catppuccin-mocha · rose-pine · everforest · gruvbox-dark. vinos-theme <name> and it's done — no restart.

Hardware-aware

Auto-detects Apple T2, NVIDIA, AMD, Intel, Dell XPS, ASUS ROG at install time. Pulls the right kernel modules, drivers, env vars, and Hyprland tweaks.

Fork-friendly

philosophy

Three rules. Never violated.

01

Desktop is a module.

Only 02-desktop.sh touches anything graphical. Every other script works headless — servers, VMs, containers, whatever.

02

Forks overlay, never edit.

Base owns 01–09. Forks own 10–99. Overlays add and shadow, never modify. Every script idempotent.

03

Identity in one place.

Only 05-branding.sh touches os-release, wallpaper, logos, or vinos-* bins. Rebranding a fork is one file.

who's this for

Honest fit-check.

✓ Yes if you

  • Already run Arch, or don't mind installing it via archinstall
  • Want Hyprland + AI tools without spending a weekend on dotfiles
  • Like opinionated defaults you can override with one line
  • Have a 2018–2020 T2 Mac and want it to feel native
  • Want your LLMs local and your keybindings sane

× Skip if you

  • Want a Windows-style graphical installer (not there yet)
  • Prefer to hand-craft dotfiles — a valid preference; ours are opinionated
  • Aren't comfortable in a terminal for at least the install step
  • Need LTS stability — this is a rolling Arch layer, updates daily
