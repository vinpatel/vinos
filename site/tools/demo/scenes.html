Higher level HTTP client library. Provides an ergonomic, batteries-included async and blocking API for making HTTP requests with JSON, forms, cookies, and streaming support. Built on hyper, tokio, and rustls.

Structs

ClientAn asynchronous Client to make requests with.
ClientBuilderA ClientBuilder can be used to create a Client with custom configuration.
RequestBuilderA builder to construct the properties of a Request.
ResponseA Response to a submitted Request.

› explain the reqwest .query() call in main.rs, quickly

llama3.2 · first token 42 ms · streaming 87 t/s

The .query() call takes a slice of (&str, &str) pairs and
URL-encodes them onto the request path. So

  .query(&[("tags", "front_page"), ("hitsPerPage", "10")])

becomes

  ?tags=front_page&hitsPerPage=10

Two nice things about this API:

  → Compile-time typed — anything that impls Serialize works,
    so you could pass a struct instead of tuples once your query
    grows past three or four parameters.

  → Escaping is free — no manual urlencoding::encode()
    dance. Spaces, colons, plus-signs all handled.

If you need repeated keys (rare in HN's API but common elsewhere),
just add the pair twice: [("t", "rust"), ("t", "async")].
