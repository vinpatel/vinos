Crate reqwest

Higher level HTTP client library. Provides an ergonomic, batteries-included async and blocking API for making HTTP requests with JSON, forms, cookies, and streaming support. Built on hyper, tokio, and rustls.

ClientBuilderA builder to configure a Client.

› what's the diff between as_array
    and get(0)? quick.

llama3.2 · 42ms · 87 t/s

Both return Option<&Value> on a Value that's
a JSON array, but:

  → as_array() gives you the whole slice
    (&Vec<Value>), None if not an array.
  → get(0) returns the first element only,
    None if empty or out of bounds.

Use as_array to iterate. Use get(i) when
you know the index up front.
