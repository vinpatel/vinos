Configuring binds

Hyprland binds are declared in hyprland.conf using the bind = MOD, KEY, DISPATCHER, ARG form. Modifiers stack with a space; leading commas are placeholders for the empty modifier set.

bind = SUPER, RETURN, exec, foot
bind = SUPER, A,      exec, vinos-ai chat
bind = SUPER SHIFT, A, exec, claude
bind = SUPER, SPACE,  exec, walker

See Dispatchers for the full list, including exec, killactive, togglefloating, and movetoworkspace.
