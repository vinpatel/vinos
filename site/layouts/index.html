{{/* ═══════════════════════ WHAT IT IS · editorial prose ═══════════════════════ */}}

Arch, refined.

Not a fork. Not a distro. A set of idempotent scripts and considered configs that sit on top of upstream Arch — the same kernel, the same pacman, the same rolling repos. Nothing hidden. Nothing patched behind your back.

The base is a fifteen-minute install: Hyprland, waybar, walker, foot, greetd, iwd, pipewire — all pre-configured, all default. On top of that eight opt-in bundles let you add an AI stack, a dev toolkit, media, games, comms — one command each. Read the bundle lists in /usr/share/vinos/bundles/. Fork them. Ignore them.

Everything is a script you can read. Every driver decision, every keybinding, every service enabled. If you leave, nothing follows.

Three steps.

Nothing tricky. If you have flashed a USB before, you can install this.

  1. 01

    Download the ISO.

    Grab vinos-{{ .Site.Params.version }}-x86_64.iso from the releases page. About 2.33 GB. SHA256 is published alongside.

  2. 02

    Flash to USB.

    Etcher, Rufus, or dd. Any 8 GB+ stick works. Five minutes.

  3. 03

    Boot and install.

    Boot from the USB. When the desktop loads, open a terminal and run:

    sudo vinos-install-disk
