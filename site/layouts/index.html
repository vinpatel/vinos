how it works

Three steps.

1

Download the ISO

Grab the vinOS ISO from GitHub. About 3 GB.

Latest release →
2

Flash to USB

Use Etcher, Rufus, or dd. Any 8 GB+ USB stick works.

~5 minutes
3

Boot and install

Boot from USB. When the desktop loads, run:

sudo vinos-install-disk

That's it. It detects your hardware (Apple T2, NVIDIA, AMD, Intel), picks the right kernel and drivers, wipes your target disk, installs everything. Reboots into a clean desktop with your AI tools ready.
