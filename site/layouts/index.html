vinOS is Linux. Specifically, it's a thin, opinionated layer over stock Arch Linux — every package, config file, and driver Omarchy would give you, wired up to boot on Apple T2 Macs, ThinkPads, Framework, Dell XPS, or any 2015+ Intel/AMD machine out of the box. Then it goes further: AI workflows one keystroke away, a bootable ISO installer, and eight opt-in bundles for the way you actually work.

how it works

Three steps.

1

Download the ISO

Grab the vinOS ISO from GitHub. About 3 GB.

Latest release →
2

Flash to USB

Use Etcher, Rufus, or dd. Any 8 GB+ USB stick works.

~5 minutes
3

Boot and install

Boot from USB. When the desktop loads, run:

sudo vinos-install-disk

That's it. It detects your hardware (Apple T2, NVIDIA, AMD, Intel), picks the right kernel and drivers, wipes your target disk, installs everything. Reboots into a clean desktop with your AI tools ready.

what's inside

An AI-native desktop.
Configured for you.

Everything Arch and Omarchy give you — plus a bootable installer, hardware drivers baked in, and AI workflows one keystroke away.

AI-native

Two keys to your AI stack

Super+A opens a terminal running vinos-ai chat — a local Ollama session with the model of your choice. Super+Shift+A opens Claude Code for agentic edits across your repo. No API keys leak, no data goes anywhere you didn't send it. The vinos-ai CLI wraps ollama, claude, and aichat behind one command — pull models, chat, run code assist, all local by default.

out-of-box

Boots on your hardware. All of it.

Drivers ship in the ISO — no post-install detection dance. NVIDIA (open kernel modules + Wayland), Intel graphics, Apple T2 Macs (2018–2020) via macbook12-spi-driver, ThinkPad, Framework, Dell XPS haptic touchpads, ASUS via asusctl. Wi-Fi, trackpad, GPU, and audio work from the moment the live USB comes up — no manual setup, no offline dead-ends.

Hyprland

A fully configured Hyprland desktop

Hyprland compositor with opinionated configs for waybar, walker (app launcher), mako (notifications), hypridle, hyprlock, hyprpicker, hyprsunset, swayosd, and satty — every keybinding, animation, gap, and blur wired to feel like Omarchy from second one. Kvantum + qt6ct for consistent Qt theming, GTK 3/4 themes, Noto CJK + emoji fonts, ready-to-use foot terminal. Nothing to configure.

themes

Five themes. Swap in one keystroke.

tokyo-night (default), catppuccin-mocha, rose-pine, everforest, gruvbox-dark. Press Super+Ctrl+T and vinos-theme --pick retints Hyprland, waybar, walker, foot, mako, and the wallpaper live — no session restart. Persona overlays (education, health) can preselect their own theme too.

bundles

Eight opt-in bundles. One command each.

The base ISO stays lean. When you need more, pick from ai, dev, media, office, gaming, productivity, comms, and browser. Each is a single vinos-install-<bundle> command. First-boot notifier shows what's available; the vinOS menu (Super+Ctrl+O) is one click away.

networking

Wi-Fi that just works

iwd + impala instead of NetworkManager — smaller, faster, and driven from a keyboard-first TUI. Super+Ctrl+W opens the Wi-Fi picker; rfkill is wired up; systemd-networkd-wait-online is masked so boots stay fast on airplanes and hotels.

keyboard-first

Every action is a keystroke

Super+K shows every binding. Super+/ generates a live cheatsheet from your current config. Walker (Super+Space) launches apps, symbols, calc, files, and clipboard history from one prompt. Once you've spent an afternoon here your hands won't leave the home row.

rolling

Arch underneath. Rolling forever.

vinOS is a thin, honest layer over stock Arch. pacman works. AUR works. Updates flow daily — no LTS purgatory, no version-locked libraries. vinos-update runs the upstream Arch update path plus a few post-hooks (mirror check, orphan sweep). When Arch ships something new, you get it.
