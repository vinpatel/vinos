{{/* ─────────────── INSTALL ─────────────── */}}
install

Three steps.

If you have flashed a USB before, you can install this.

  1. 01

    Download the ISO.

    Grab vinos-{{ .Site.Params.version }}-x86_64.iso from the archive.org page. About 4.3 GB. Verify the sha256sum before you flash.

  2. 02

    Flash to USB.

    Etcher, Rufus, or dd. Any 8 GB+ stick works. Five minutes.

  3. 03

    Boot and install.

    Boot from the USB. When the desktop loads, open a terminal and run:

    sudo vinos-install-disk
