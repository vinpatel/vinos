description: "Download the ISO, verify it, flash to USB, boot, and drop your API keys in the right place. About 20 minutes end-to-end."

---

Four things stand between you and a working vinOS install: a **verified
ISO on a USB stick**, a **first boot** past hardware detection, **Wi-Fi**,
and your **API keys** for Claude Code and Ollama. Each is one page.

The whole track takes 15–25 minutes on a modern machine. Longer on a T2
Mac only because the wifi firmware handshake takes a beat to warm up.
